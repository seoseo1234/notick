# 포도알 네이티브 클릭 도우미

크롬 확장 프로그램의 스크립트 클릭 대신 Windows의 실제 마우스 입력을 보내는 별도 도구입니다. 외부 Python 모듈이나 별도 설치 프로그램 없이 Windows PowerShell과 .NET 기본 라이브러리로 실행합니다.

## 실행

1. 검은 터미널 창과 이전 도우미 창을 닫고, 압축을 푼 폴더에서 `run.bat`을 더블클릭합니다. 터미널은 숨겨지고 도우미 창만 표시됩니다.
2. **브라우저 창**에서 좌석도가 열린 Chrome/Edge 창을 고릅니다.
3. 브라우저의 좌석도 화면에서 **좌석도 범위 지정**을 누르고 좌석 점과 좌우 끝의 숫자 라벨까지 포함해 드래그합니다. 범례, 확대 버튼, 페이지 버튼은 범위에 넣지 마세요.
4. **후보 미리 확인**을 누릅니다. “열 번호 방향 인식”이 표시되어야 시작할 수 있습니다. 라벨 방향을 못 찾으면 숫자가 잘리지 않게 범위를 다시 잡으세요.
5. 최대 1~4석을 고르고 **시작 (실제 클릭)**을 누릅니다.

실행 중에는 프로그램 창이 숨고 좌석도에 네이티브 마우스 클릭을 보냅니다. 회전/기울어진 좌석 격자를 보정하고, 같은 줄에서 실제로 이웃한 후보만 묶습니다. 가능한 경우 최대 좌석 수를 연속으로 클릭하고, 그만큼 붙은 자리가 없으면 가능한 연속 좌석 수로 내려갑니다. Chrome이 최대화된 상태는 유지합니다. F8을 누르면 멈춥니다.

## 좌석 선택 순서

- 지도에서 회색 점은 비활성 좌석으로 보고 제외합니다. 빨강·초록·보라 등 색이 있는 원형 좌석은 후보에 포함합니다.
- 제공된 우선순위 색과 가까운 좌석을 먼저 보며, 목록에 없는 색도 마지막 순위로 선택 대상에 포함합니다.
- 좌석 양끝 숫자 라벨들의 배열 방향으로 열 방향을 추정해, 다른 열에 걸친 좌석 묶음을 만들지 않습니다. 숫자 값이나 앞열 순서는 판별하지 않습니다. 붙은 좌석 수와 통로 쪽 끝, 색상 우선순위를 적용합니다.
- 감시 주기를 1ms로 설정하고 묶음을 한 번에 클릭합니다. 실제 반응 시간은 화면 캡처/좌석 수와 브라우저 처리 속도에 따라 달라집니다.
- 좌석 지점에 실제 마우스를 이동해 누르므로 브라우저 확장 프로그램의 스크립트 클릭보다 사이트에서 실제 클릭처럼 처리될 가능성이 높습니다.

## 주의

- **범위를 좌석도에만 맞추세요.** 범위 안에 다른 색 원형 아이콘이 있으면 잘못 선택할 수 있습니다.
- 좌석도 위치를 옮기거나 확대율을 바꾸면 범위를 다시 지정하고 후보 미리 확인을 하세요.
- 화면에서 점을 인식하는 방식이라 공연장별 색/표시 방식에 따라 빈 좌석과 색 점을 구분하지 못할 수 있습니다. 시작 전 후보 수를 확인하고, 실행 중에는 좌석 선택 상태를 살펴보세요.
- 한 묶음의 연속 좌석을 클릭한 뒤 화면에서 활성화된 **선택 완료** 버튼을 찾아 마우스로 누릅니다. 버튼을 찾지 못하면 도우미 상태창에 직접 누르라고 표시합니다. 다음 단계, 예매 확정, 결제 버튼은 누르지 않습니다.
- 좌석 묶음을 선택하면 감시를 종료합니다. 최대 수보다 적은 연속 좌석만 발견한 경우에도 그 묶음을 선택하고 완료 버튼을 누릅니다.
